# Resonance — обновления

Здесь лежат сборки Android-приложения **Resonance** для встроенного обновления.

Приложение проверяет этот репозиторий из **Настройки → О приложении → Обновление**
и предлагает поставить свежую версию, если она новее установленной.

Исходный код приложения закрыт и в этот репозиторий не попадает.

## Установка вручную

1. Скачайте `.apk` из [последнего релиза](https://github.com/pumpdog/resonance-apk/releases/latest).
2. Откройте файл на телефоне и разрешите установку из этого источника.
